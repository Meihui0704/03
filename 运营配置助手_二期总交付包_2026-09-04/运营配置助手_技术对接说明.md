# 运营配置助手｜技术对接说明

版本：V1（样板模块）  
范围：广告素材管理、金刚区管理（含磁片区）

## 1. 接入边界

- 前端目标环境：Vue 2 + Element UI + Vue CLI。
- 复用现有后台登录、菜单、路由、权限、数据库和文件上传能力。
- Demo 中的静态数据仅用于展示交互；项目、专业、页面、商品、试卷等选项全部由接口返回。
- CSS 只作用于当前页面，避免覆盖现有后台全局样式。
- 所有写操作由后端再次校验，不以浏览器校验作为最终依据。

## 2. 通用枚举

| 字段 | 建议值 | 含义 |
|---|---|---|
| status | ON / OFF | 使用中 / 已停用（广告素材页文案可显示为上架 / 已下架） |
| appCode | APP / MINI_PROGRAM / PC | 昭昭医考 App / 小程序 / 网校 PC 端 |
| openMode | APP_IN / APP_OUT / MINI | App 内打开 / 外部链接 / 小程序 |
| entryPosition | DIAMOND / TILE | 金刚区 / 磁片区 |
| adType | BANNER / POPUP / FLOATING / SPLASH | 轮播图 / 弹层 / 悬浮广告 / 开屏广告 |

## 3. 广告素材管理

### 输入字段

| 字段 | 类型 | 必填 | 来源/说明 |
|---|---|---:|---|
| id | number | 编辑时 | 后端生成 |
| adType | enum | 是 | 广告形式 |
| appCode | enum | 是 | 投放应用 |
| pageCode | string | 是 | 页面字典接口 |
| positionCode | string | 轮播图必填 | 图 1、图 2 等位置字典 |
| projectIds | number[] | 是 | 项目字典接口 |
| professionIds | number[] | 是 | 随项目联动 |
| targetType | string | 是 | 商品、普通页面、外部链接、无跳转 |
| productType | string | 商品时必填 | 必须由真实商品类型接口返回 |
| targetId / targetUrl | string | 条件必填 | 商品/页面 ID 或 https 链接 |
| imageUrl | string | 是 | 上传接口返回 |
| startAt / endAt | datetime | 是 | 投放有效期 |
| sortNo | number | 轮播图必填 | 同位置展示顺序 |
| status | enum | 是 | 新增、复制默认 OFF |

### 输出结果

- 保存：返回记录 ID、版本号、修改人、修改时间和最终状态。
- 复制：返回全部副本 ID；副本默认下架。
- 上下架：返回变更后的状态及冲突校验结果。
- 批量操作：返回成功 ID、失败 ID、失败原因，允许部分成功。
- 撤回：使用操作流水号恢复数据和前端操作前筛选上下文。

## 4. 金刚区管理（含磁片区）

### 输入字段

| 字段 | 类型 | 必填 | 来源/说明 |
|---|---|---:|---|
| id | number | 编辑时 | 后端生成 |
| name | string | 是 | 建议 2–6 字，最大长度以后端为准 |
| iconUrl | string | 是 | 建议 80×80；尺寸由上传接口校验 |
| appCode | enum | 是 | App 或小程序 |
| pageCode | string | 是 | 当前为首页，仍保留接口字段 |
| entryPosition | enum | 是 | 金刚区或磁片区 |
| projectIds | number[] | 是 | 支持多选 |
| professionIds | number[] | 是 | 支持多选，必须属于已选项目 |
| openMode | enum | 是 | App 内、App 外、小程序 |
| targetPageCode | string | 条件必填 | 打开对象字典 |
| targetContentId | string | 条件必填 | 商品、试卷、试题、活动等真实 ID |
| externalUrl | string | 外链时必填 | 只接受 https |
| miniAppId / miniPath | string | 小程序时必填 | 小程序标识和页面路径 |
| validityType | LONG_TERM / RANGE | 是 | 长期或时间段 |
| startAt / endAt | datetime | RANGE 时必填 | 生效时间 |
| status | enum | 是 | 去向不完整时禁止 ON |

### 打开对象字典

已确认：`HONOR` 的业务文案为“App 刷题排行榜”，即投射在 App 上的刷题排名页面。  
其他对象如试卷详情页、试题详情页、商品列表页、商品详情页、活动管理页、模拟考试、周考排行由技术提供正式 code 和名称。

### 输出结果

- 保存基础信息：返回入口 ID、版本号和待配置项。
- 保存去向：返回标准化目标摘要，供列表和预览复用。
- 启用：返回冲突清单；无阻断冲突时返回 ON。
- 预览：返回完整字段、最终跳转目标、展示范围和有效期。
- 批量启停/删除：逐条返回结果，不因单条失败吞掉全部反馈。

## 5. 冲突校验规则

### 阻断保存或启用

1. 必填字段缺失、图片上传失败或目标 ID 不存在。
2. 结束时间早于或等于开始时间。
3. App 外打开但链接不是完整 `https://` 地址。
4. 小程序打开但缺少 AppID 或页面路径。
5. 目标内容已删除、已停用或不属于所选项目/专业。
6. 专业不属于所选项目。
7. 同一应用、页面、位置、项目、专业及重叠有效期内，出现不允许并存的唯一位置记录。
8. 轮播图同一投放范围、同一有效期内 `sortNo` 重复。

### 允许保存草稿，但禁止启用

- 尚未配置点击去向。
- 尚未上传合规图片或图标。
- 目标内容状态不可用。
- 有效期未填写完整。

### 仅提示确认

- 同一素材投放到多个专业。
- 同一目标被多个入口引用。
- 批量操作包含不同项目或不同页面。
- 修改正在前台使用的记录。

冲突唯一性最终由产品和技术确认；建议接口返回 `BLOCK`、`WARN`、`PASS` 三级结果及可读原因。

## 6. 建议接口

| 方法 | 路径示例 | 用途 |
|---|---|---|
| GET | `/api/ops/dictionaries` | 应用、页面、位置、打开对象等字典 |
| GET | `/api/ops/projects` | 项目与专业树 |
| GET | `/api/ops/ads` | 广告素材列表 |
| POST/PUT | `/api/ops/ads` / `/api/ops/ads/{id}` | 新增、编辑广告素材 |
| POST | `/api/ops/ads/{id}/copy` | 复制 1/5/10 条 |
| POST | `/api/ops/ads/batch-status` | 批量上下架 |
| GET | `/api/ops/entries` | 金刚区/磁片区列表 |
| POST/PUT | `/api/ops/entries` / `/api/ops/entries/{id}` | 新增、编辑入口 |
| PUT | `/api/ops/entries/{id}/destination` | 单独修改点击去向 |
| POST | `/api/ops/validate-conflicts` | 保存或启用前冲突校验 |
| POST | `/api/ops/operations/{operationId}/undo` | 撤回最近一次可撤回操作 |
| POST | `/api/files/images` | 图片/图标上传 |

## 7. 权限与审计

- 权限建议拆分：查看、新增、编辑、上下架、批量操作、删除。
- 写操作记录 operatorId、operatorName、operationId、before、after、createdAt。
- 删除是否物理删除由现有后台规范决定；前端统一显示明确警告。
- 撤回有效期建议由后端返回 `undoExpireAt`，不要由前端自行判断。

## 8. 前端统一反馈文案

- 成功：说明“改了什么、影响几条、去哪里查看”。
- 部分失败：说明成功数、失败数，并允许查看逐条原因。
- 阻断：直接说明缺失字段或冲突对象，并提供返回修改入口。
- 删除：确认框必须显示记录名称、ID 和影响数量。
- 撤回：恢复数据，同时恢复操作前的筛选、分类、排序和滚动位置。

## 9. 技术确认项

1. 正式项目/专业树接口及 13 个一级项目的真实 code。
2. 广告形式、显示页面、位置和商品类型的正式字典。
3. 各打开对象所需的 targetId、路由参数和可用状态规则。
4. “周考排行”和“App 刷题排行榜”是否为两个独立路由。
5. 唯一位置和有效期重叠的最终冲突规则。
6. 批量接口是否支持部分成功及最大条数。
7. 删除、撤回和操作日志的现有后台规范。
