# 运营配置助手｜项目背景与技术交接总说明

更新时间：2026-09-04  
当前阶段：二期领导演示版（可交互原型）

## 1. 一句话说明

这个项目不是重新发明一套后台，而是在真实后台的数据、ID、权限和接口之上，增加一层更容易理解和更适合批量操作的运营工作台。

一期 HTML 中已经整理好的商品、课程和优惠券业务被原生迁入 Vue 2 工程；已经确认的广告素材、金刚区/磁片区、AI 工具、意见反馈、免费体验课页面继续保留，不因一期迁入而被重做。

## 2. 项目背景与两期关系

### 一期

- 来源文件：`/Users/meihui/Downloads/运营配置助手_demo最终版.html`。
- 由用户与 Claude Code 共同完成。
- 主要价值：把“项目 → 专业 → 商品 → 运营操作”的关系整理成领导能看懂、运营能执行的流程。
- 主要内容：13 个项目、专业方向、临床商品、中级职称商品、优惠券配置、商品课程上下架和商品调价。

### 二期

- 目标：把一期的人类可读交互原生迁入 Vue 2 + Element UI 后台外壳，并接入后来梳理的运营模块。
- 迁移不是复制旧页面视觉，也不是把一期页面嵌入新页面；而是保留一期业务内容和流程，用统一组件重新实现。
- 本期主要用于给非技术领导演示。因此交互要完整、关系要直观；真实写接口和生产权限不在本期范围内。

### 冻结边界

- 广告素材管理：以 `运营配置助手_轮播图管理_V1.html` 为已确认基线。
- 金刚区管理：以 `运营配置助手_金刚区管理_V1.html` 为已确认基线；金刚区与磁片区属于同一“首页入口管理”模块。
- 一期 HTML 只进入商品与优惠券相关页面，不覆盖上述已确认模块。
- 未经再次确认，不修改左侧菜单名称、不新增业务名词、不猜测真实接口枚举。

## 3. 真实后台目前是什么样

以下来自用户提供的真实后台截图和沟通，不是代码推测：

- 后台采用左侧导航、查询条件、列表表格、行级操作和弹窗表单的传统管理后台模式。
- 项目、专业和子级是三级关系；项目 ID、专业 ID、子级 ID 都是实际身份键。
- 项目/专业列表原先把多种项目和状态混在长表中，默认排序不明确，运营进入页面后很难快速建立“地图”。
- 上架和下架需要明确分开查看，不能选完状态后还要再点一次查询。
- 金刚区和磁片区在一个模块中管理；每个入口都必须配置最终点击去向。
- “光荣榜”的真实业务含义已经确认：投射在 App 上的刷题排行榜。演示和对接文档统一写为“App 刷题排行榜”。
- AI 工具集固定有 6 个 App 中部智能体入口；附属配置包含推荐提问和营销管理，推荐管理目前没有关联商品。
- 意见反馈当前是查询和查看回复的处理列表，没有确认启用/停用能力。
- App 免费体验课属于引流课任务，包含任务配置和关联小节。

尚不能从截图确认真实后台的服务端语言、数据库类型和接口协议细节；这些不能自行写入结论。

## 4. 和技术对接后采用的前端模型

### 已确认技术栈

- Vue `2.7.16`
- Vue Router `3.6.5`
- Element UI `2.15.14`
- Vue CLI Service `5.0.8`
- JavaScript + 原生 CSS
- 单文件组件 `.vue`
- Hash 路由，便于静态演示与后台路由接入

### 当前产品模型

```text
展示层：业务地图、清单、分步表单、影响预览、操作反馈
规则层：项目/专业/商品关系、适用范围、状态、冲突和必填校验
适配层：以后把批量意图拆成真实后台接口能够接收的请求
事实层：继续使用原后台的 ID、状态、权限、数据和操作结果
```

### 当前数据模型

- 当前是前端可交互 Demo，不是生产后台。
- 商品与优惠券跨页面选择暂存于 `sessionStorage`。
- 广告素材和首页入口的演示变更暂存于 `localStorage`，刷新后仍可看见。
- 没有真实数据库连接、账号密码、密钥或生产接口。
- 上线时必须用后端返回的真实 ID 和枚举替换演示数据，所有写操作必须由后端再次校验。

## 7. 已恢复的已确认模块

### 广告素材管理

- 保留“广告素材管理”名称，不改成新业务名词。
- 默认 8 条演示素材，覆盖轮播图及其投放位置、展示对象、去向、有效期和状态。

### 首页入口管理（金刚区 + 磁片区）

- 左侧仍叫“金刚区管理”，页面标题为“首页入口管理”。

- “更多”菜单挂载到页面顶层，滚动或表格裁切时不会被容器遮住；菜单字号与其他操作一致。
- App 内去向包含试卷详情页、试题详情页、商品列表页、商品详情页、活动管理页、模拟考试、周考排行、App 刷题排行榜。
- 需要具体内容的去向必须选择内容 ID；外链必须是 `https://`；小程序必须填写 AppID 和页面路径。

## 8. 通用交互和校验口径

### 通用状态

- 正向状态：使用中、启用、已上架。
- 负向状态：已停用、已下架。
- 页面文案按业务语境显示，但接口建议统一为 `ON / OFF`。

### 阻断执行

- 必填字段缺失。
- 结束时间早于开始时间。
- 专业不属于所选项目。
- 商品、试卷、试题或页面 ID 不存在或不可用。
- App 外链接不是完整 `https://`。
- 小程序缺少 AppID 或页面路径。
- 同一投放位置和重叠有效期内出现不允许并存的唯一记录。
- 轮播图同一范围、同一有效期内排序重复。

### 只提示、不直接阻断

- 同一素材覆盖多个专业。
- 同一目标被多个入口引用。
- 批量操作跨多个项目或页面。
- 修改正在前台使用的记录。

建议后端统一返回 `PASS / WARN / BLOCK` 和可读原因；批量接口应逐条返回成功、失败和失败原因。
