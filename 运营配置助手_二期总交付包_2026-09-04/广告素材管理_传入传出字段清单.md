# 广告素材管理：传入／传出字段清单

> 用途：业务与技术对齐接口信息。本文档只确定业务含义，实际接口地址、字段编码、枚举值和权限由技术确认。

## 1. 列表查询

### 传入（前端提交给后台）

| 业务字段 | 用途 | 是否必填 | 备注 |
|---|---|---:|---|
| 项目 | 按一级项目筛选 | 否 | 使用正式项目 ID，不只传名称 |
| 专业 | 按二级专业筛选 | 否 | 受项目限制 |
| 显示应用 | App／小程序／PC | 否 | 枚举值待确认 |
| 广告形式 | 轮播图／弹层／悬浮／开屏 | 否 | 枚举值待确认 |
| 显示页面 | 按投放页面筛选 | 否 | 需要页面 ID／编码 |
| 状态 | 使用中／已下架／全部 | 否 | 状态枚举待确认 |
| 下架时间范围 | 今天／一周／一月／全部 | 否 | 只在查看已下架时使用 |
| 关键词 | 搜索广告 ID、商品或专业 | 否 | 后台确认支持的搜索字段 |
| 排序 | 修改时间／有效期 | 否 | 需支持升序与降序 |
| 页码、每页条数 | 分页 | 是 | 最大每页条数待确认 |

### 传出（后台返回给前端）

| 业务字段 | 用途 | 备注 |
|---|---|---|
| 广告 ID | 唯一标识 | 编辑、复制、上下架均依赖 |
| 广告形式 | 区分轮播图、弹层、悬浮和开屏 | 展示正式名称与编码 |
| 图片地址 | 显示缩略图 | 需返回可访问的图片 URL |
| 显示应用、页面、顺序 | 显示投放位置 | 非轮播图可无顺序 |
| 项目 ID／名称 | 显示一级项目 | 同时返回 ID 与名称 |
| 专业 ID／名称 | 显示二级专业 | 同时返回 ID 与名称 |
| 点击目标类型 | 商品／页面／外链／无跳转 | 枚举值待确认 |
| 商品类型 | 课程／题库／音频／面授／AI 工具／服务 | 来自旧后台界面，编码待确认 |
| 商品 ID／名称 | 显示图片点击去向 | 不能只传商品名称 |
| 页面 ID／外部 URL | 非商品跳转目标 | 按目标类型返回 |
| 有效开始、结束时间 | 控制投放时间 | 时区和时间格式待确认 |
| 状态 | 使用中／已下架 | 不只依靠文字颜色区分 |
| 最后修改人、时间 | 审计与追溯 | 由后台记录，不由前端伪造 |
| 总条数 | 分页与数量展示 |  |

## 2. 商品搜索

### 传入

| 字段 | 说明 |
|---|---|
| 项目 ID | 限定当前项目 |
| 专业 ID | 限定当前专业 |
| 商品类型 | 课程／题库／音频／面授／AI 工具／服务 |
| 关键词 | 商品名称或商品 ID |
| 是否只返回可售商品 | 规则待技术／业务确认 |

### 传出

| 字段 | 说明 |
|---|---|
| 商品 ID | 保存时必须传入的真实 ID |
| 商品名称 | 前端展示 |
| 商品类型 | 用于校验 |
| 所属项目、专业 | 用于展示完整跳转路径 |
| 商品状态 | 在售／停售／其他状态，枚举待确认 |

## 3. 新增／编辑保存

### 传入

| 字段 | 是否必填 | 说明 |
|---|---:|---|
| 广告 ID | 编辑必填 | 新增时由后台生成 |
| 显示应用 | 是 |  |
| 广告形式 | 是 |  |
| 显示页面 | 是 |  |
| 显示顺序 | 条件必填 | 轮播图必填，其他形式根据规则确认 |
| 项目 ID | 是 |  |
| 专业 ID | 是 | 如支持多选，需确认是数组还是拆分记录 |
| 点击目标类型 | 是 |  |
| 商品类型、商品 ID | 条件必填 | 选择商品时必填 |
| 页面 ID | 条件必填 | 选择普通页面时必填 |
| 外部 URL | 条件必填 | 选择外部链接时必填 |
| 图片地址／上传结果 ID | 是 | 先确认现有图片上传方式 |
| 有效开始、结束时间 | 是 |  |
| 保存状态 | 是 | 新增默认下架 |
| 版本号／最后修改时间 | 建议必填 | 用于防止多人同时编辑覆盖 |

### 传出

| 字段 | 说明 |
|---|---|
| 是否成功 | 成功／失败 |
| 广告 ID | 新增时返回新 ID |
| 最终状态 | 用于自动跳转到对应列表 |
| 最后修改人、时间 | 由后台生成 |
| 校验错误 | 字段、错误编码、可读提示 |
| 最新版本号 | 用于后续编辑 |

## 4. 上架前校验与上下架

### 校验传入

- 单条：广告 ID。
- 批量：广告 ID 数组。

### 校验传出

| 字段 | 说明 |
|---|---|
| 可否上架 | 整体结果 |
| 广告 ID | 对应每条校验结果 |
| 冲突类型 | 顺序、栏位、时间、图片、商品状态等，以后台真实规则为准 |
| 冲突详情 | 需返回冲突对象 ID 和可读文案 |
| 处理建议 | 可修改顺序／时间／先下架冲突项等 |

### 上下架传出

| 字段 | 说明 |
|---|---|
| 是否成功 | 批量时不能只返回一个总结果 |
| 每条广告的结果 | 广告 ID、成功／失败、失败原因 |
| 最终状态 | 用于页面自动定位 |
| 操作批次 ID | 用于日志和整批撤回，是否支持待确认 |
| 操作人、时间 | 由后台生成 |

## 5. 复制

### 传入

- 源广告 ID。
- 复制数量：1／5／10。
- 目标状态：默认下架。

### 传出

- 新广告 ID 数组。
- 每条复制结果及失败原因。
- 操作批次 ID（如支持整批撤回）。

## 6. 删除与撤回

需技术首先确认：

1. 当前删除是物理删除还是软删除。
2. 是否已有恢复接口。
3. “15 秒撤回”由前端延迟提交，还是由后台提供恢复能力。
4. 批量删除是全部成功才提交，还是允许部分成功。

## 7. 图片上传

### 传入

- 图片文件。
- 广告形式，用于尺寸和比例校验。

### 传出

- 上传结果 ID 或图片 URL。
- 原图宽高、文件大小、文件类型。
- 是否符合当前广告形式的尺寸规则。
- 失败时返回明确原因和要求尺寸。

## 9. 对齐原则

- 前端传 ID，名称用于展示；不使用名称代替关联 ID。
- 操作人、操作时间和最终状态以后台返回为准。
- 批量操作必须返回每条记录的结果，不能只显示“操作成功”。
- 上架、删除和批量操作必须有可追溯的操作批次或日志。
- 接口返回的失败原因必须能对应到具体广告和具体字段。
