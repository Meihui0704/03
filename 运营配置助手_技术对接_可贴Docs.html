运营配置助手｜技术对接说明

整理：运营（美惠）　日期：2026-09-08　给技术对齐用，不是再画页面。

0. 一句话

项口径
定位盖在原后台之上的运营工作台。新版页面 → 原后台接口 → 原数据库 → App / 小程序 / PC。
不做什么不新建商品库；不改原 ID；不改原权限；不编未确认售价、小节 ID、活动、推荐商品。
谁拍板入口和任务形态听运营；现用字段听张旭；接口、校验、搜索、撤回落库听技术。

1. 职责分工

角色拍板范围
运营（美惠）工作台入口位置、左侧名称、批量怎么操作（一屏填规则、按科室勾专业、一次生成）。
张旭 / 现网后台哪些字段还在用、枚举和售价、试听内容从哪来。已停用模块不要按旧图恢复。
技术接口、拆请求、服务端校验、权限、商品搜索、撤回、分页、上传。

已确认例子：旧「App免费体验课」的配置内容 / 关联小节长期不用。现网是商品页「配置头图免费试听 / 配置列表免费试听」。入口在「App引流课管理」，名称按运营，字段按张旭。

2. 全局写入规则（优惠券、上下架、调价同一套）

规则运营已确认口径
一次保存同一规则落到所有有效「商品 × 专业」。后台若只能逐条写，由适配层拆成 N 次请求，对运营仍是一次任务。
覆盖不到的专业跳过，不写脏数据，结果里标明原因。不要每个专业再走一遍向导。
15 秒内撤回允许。必须整批收回，禁止一半有券一半没有。
撤回之后这次任务作废，重新选范围再保存，不在半成品上续写。
超过 15 秒不能靠这个撤回。之后走后台正常下架 / 删除 / 再配一批。
写入中途失败同样整批作废，明确告诉失败原因。不要静默部分成功。
撤回实现必须服务端提供（操作单号 / 短时快照）。有效期由后端返回 undoExpireAt，不要前端自己倒计时当真。
幂等短时间重复点保存，不能发两批真实券或调价。需任务号或幂等键。

3. 价格与亏本

项口径
前端测算价仅供参考，不是最终能否保存的依据。
成交价 ≥ 0可以保存（等于 0 也可以）。
成交价 < 0拦截亏本。
满减门槛可以为 0（满 0 减 N 允许配）。
无售价商品前端不编价格（含中级职称精英班等）。只提示无法确认是否低于 0。
最终拦截必须用后台当时真实售价再算一遍。前端过、后台不过，以后台为准。

4. 工程接入（已迁页面通用）

事项要求
演示数据localStorage / sessionStorage 不能当真源。列表、详情、写操作走原接口。
ID项目、专业、子级、商品、广告、页面一律用后台 ID。
权限按钮接原权限。演示操作人「美惠」不能当生产身份。
校验必填、状态、冲突、有效期、图片，服务端再校验一次。
操作人返回最后修改人、修改时间。
枚举code 以后台字典为准，前端不发明新枚举。

5. 按模块要对齐的事

模块要对齐的事项
项目管理上架 / 已下架分开。所属项目为空的专业进「信息待补充」，不猜填 ID。子级无真实 ID 不编。删除 / 下架的服务端影响面需技术说明。
广告素材去向选商品必须搜索真实商品 ID，原型手填作废。图片走现有上传。像素以后台为准。列表服务端分页。复制 1/5/10 条由后台生成新 ID，默认今日下架。新记录默认下架。
金刚区（含磁片区）去向不完整不能启用。落到商品同样搜 ID。「光荣榜」= App 刷题排行榜，route code 由接口返回。项目专业树与项目管理同一数据源。15 秒整批撤回与广告相同。
AI 工具集App 中部 6 个入口，不擅自增删。「推荐管理」现网未关联商品，不要编推荐商品。
意见反馈工作台先分未处理 / 已处理；落库仍用待处理、处理中、已回复、已关闭。不要假设有启停能力。
App 优惠券列表是任务维度，不是每张券一张工单。一次保存拆 N 条；失败或 15 秒撤回 = 整批作废。生效 / 截止必填，截止不能早于生效。
上下架一屏完成，不要四步向导。生效 + 截止都必填。上架：生效起可售、截止后停售。下架：生效起停售、截止结束本次窗口。是否自动恢复上架以后台为准。
批量调价只要生效时间。亏本、权限、15 秒整批撤回与优惠券同一套。
清单带入批量用任务草稿或查询参数，不要依赖浏览器临时存储。
App 引流课对应「配置头图免费试听」「配置列表免费试听」。头图一条，列表可多条。第一个下拉走商品接口。第二个下拉等试听内容接口，禁止编小节 ID。旧关联小节不要接入。
商品清单挑货入口，不是项目管理。售价和覆盖专业来自现网。无价就保持无价。

6. 本期不要做、也不要编数据

左侧入口口径
活动列表只标明入口。接入用原活动接口和 ID，不编活动。
活动分类管理沿用原分类接口和 ID，不另建一套。
App 商品推荐管理按原推荐规则读写，不编推荐商品。

8. 验收合格标准

项合格看起来怎样
批量写一次保存后，要么完整一批，要么完整没有。
撤回15 秒内撤回后，App 看不到这批券 / 这批价。
价格无售价商品没有被写死一个编出来的价格。
广告去向能搜到真实商品 ID。
引流课第二个下拉要么有真数据，要么空，没有假小节。
边界原 ID、权限、App 展示与改版前一致，只是运营路径变短。

12. 冲突校验

级别情形
阻断保存或启用必填缺失、图片失败、目标 ID 不存在；结束时间 ≤ 开始时间；外链不是完整 https；小程序缺 AppID 或路径；目标已删/停用或不属于所选项目专业；专业不属于所选项目；同一应用+页面+位置+项目+专业+重叠有效期内不允许并存；轮播图同范围同有效期 sortNo 重复。
可存草稿，禁止启用未配去向；未上传合规图；目标不可用；有效期不完整。
仅提示确认同一素材投多个专业；同一目标被多个入口引用；批量跨项目或跨页面；改正在前台使用的记录。

建议接口返回 BLOCK / WARN / PASS 及可读原因。唯一性规则最终由产品和技术确认。
