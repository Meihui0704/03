# 运营配置助手二期交付说明

完整背景、页面边界、数据口径、接口范围和全部文件清单见上级目录的 `项目背景与技术交接总说明.md`。

## 已确认技术栈

- Vue 2
- Element UI
- Vue CLI
- Vue、JavaScript 和 CSS 写在同一个 `.vue` 文件中
- CSS 仅影响当前页面
- 使用原生 CSS，不使用 Less／Sass

## 交付文件

- `AdvertisingMaterial.vue`：广告素材管理已确认版本的 Vue 2 原生组件。
- `DiamondZoneManagement.vue`：金刚区与磁片区统一的首页入口管理组件。
- `src/views/ProjectManagement.vue`：项目、专业、信息待补充、已下架和子级管理。
- `src/data/backendHierarchy.js`：真实后台截图整理出的 24 个项目、157 个专业和子级演示数据。
- `src/views/CouponConfig.vue`：一期优惠券配置迁入后的 App 优惠券管理。
- `src/views/ProductCatalog.vue`：全部项目清单和临床商品清单。
- `src/views/ProductOperation.vue`：商品课程上下架和商品批量调价。

统一工程的左侧菜单使用「商品课程上下架」作为正式名称，覆盖商品与课程的批量上下架操作。

## 本地运行

```bash
npm install
npm run serve
```

生产构建：

```bash
npm run build
```

## 开发接入

1. 保留现有后台登录、权限、菜单与接口体系。
2. 按 `src/router/index.js` 的路由关系接入所需组件。
3. 将组件内的演示数组和浏览器存储替换为真实列表、详情和写接口。
4. 使用真实项目、专业、子级、商品和页面 ID；名称只用于展示。
5. 将按钮权限接入现有权限方法或权限指令。
6. 写操作在后端完成必填、状态、冲突和权限校验。

## 未包含内容

- 生产数据、账号、密码或密钥
- 真实接口地址
- 数据库连接
- 原后台登录与权限实现
- 未经技术确认的枚举编码和商品数据

## 页面能力

- 项目 → 专业 → 子级三级资料管理
- 项目和专业日常列表只显示上架数据，新下架数据进入独立列表
- 专业按所属项目定位，并提供信息待补充视图
- 子级新增、编辑、连续排序、上下架、删除和撤回
- 一级项目和二级专业筛选
- 使用中／已下架／全部状态切换
- 下架时间范围筛选
- 应用、广告形式、页面和排序筛选
- 逐条勾选、当前页全选和批量删除框架
- 新增、编辑、复制、上下架和删除框架
- 轮播图、弹层、悬浮和开屏广告的统一编辑框架
- 商品、普通页面、外部链接和无跳转的条件字段
- 图片上传、时间范围和保存校验框架

## 金刚区页面能力

- 一级项目、二级专业、启停状态和高级条件筛选
- 外层展示范围与点击去向分开配置
- App 内、App 外和小程序三种打开环境
- 已确认“光荣榜”为 App 刷题排行榜；正式 route code 仍由技术接口返回
- 需要具体内容的页面，在同一窗口中筛选并选择试卷、试题或商品
- 选择结果同时保存名称和 ID，并显示最终点击结果摘要
- 校验后批量启用、批量停用、批量删除、复制 1／5／10 条和长提示框架
